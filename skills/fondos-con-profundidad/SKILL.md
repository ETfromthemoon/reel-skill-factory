## Define el problema

1. Revisa la captura o el diseño y localiza la zona que se ve plana. Identifica el titular, el dato o la acción que debe leerse primero. Si falta información imprescindible, pide una captura o una descripción de la pieza, su contenido prioritario y los tamaños de salida previstos.
2. Decide qué aportaría el fondo al contenido: una sensación material, profundidad ambiental, una estructura gráfica o una imagen con carácter. Usa el catálogo para elegir dos tratamientos que sirvan a esa intención y explica qué aportaría cada uno.

## Catálogo de tratamientos

1. **Textura de fieltro** (*Felt texture*). Usa una superficie de fibras suaves para dar una sensación artesanal.
2. **Vidrio acanalado** (*Fluted glass*). Usa estrías verticales para sugerir refracción y separación entre planos.
3. **Degradados térmicos** (*Thermal gradients*). Concentra los tonos cálidos en focos luminosos rodeados de tonos fríos.
4. **Ondulaciones de agua** (*Water ripples*). Usa reflejos ondulados para sugerir una superficie líquida.
5. **Grafito moteado** (*Speckled graphite*). Usa una base oscura con motas finas y una zona de luz suave.
6. **Paisajes de un solo matiz** (*Single-hue landscapes*). Separa los planos del paisaje con valores claros y oscuros de un mismo matiz.
7. **Retículas de plano técnico** (*Blueprint grids*). Usa líneas finas sobre una base uniforme para sugerir un dibujo técnico.
8. **Semitono** (*Halftone*). Usa una trama de puntos de tamaño variable para reproducir el efecto de impresión.
9. **Degradados granulados** (*Grainy gradients*). Superpone grano fino a una transición suave de color.
10. **Textura de césped** (*Grass texture*). Usa una superficie vegetal para situar la pieza en un contexto exterior.
11. **Imágenes con tramado digital** (*Dithered images*). Reduce la paleta y usa un patrón de píxeles para simular tonos intermedios.
12. **Textura de papel** (*Paper texture*). Usa fibras, marcas o pliegues suaves para dar un carácter editorial.
13. **Curvas de nivel** (*Contour lines*). Usa líneas que sigan formas de relieve para sugerir topografía.
14. **Cielo con nubes** (*Cloud sky*). Aprovecha las zonas despejadas para el texto y las nubes para aportar volumen.
15. **Mosaicos de píxeles** (*Pixel mosaics*). Fragmenta una imagen en bloques visibles y reserva una zona tranquila para el contenido.
16. **Distorsión de lente** (*Lens distortion*). Deforma la imagen de fondo para dar carácter óptico a la escena.
17. **Degradados punteados** (*Stippled gradients*). Cambia la densidad de los puntos para construir la transición tonal.
18. **Retículas de puntos cuadrados** (*Square-dot grids*). Distribuye cuadrados pequeños a intervalos regulares para dar ritmo a la superficie.
19. **Fotos desenfocadas** (*Blurred photos*). Conserva las masas de color de una foto y suaviza sus detalles detrás del texto.
20. **Formas iridiscentes** (*Iridescent shapes*). Usa formas con reflejos multicolor como acento lejos del contenido prioritario.
21. **Pinturas impresionistas** (*Impressionist paintings*). Usa pinceladas visibles como entorno y coloca los controles sobre superficies de lectura estables.
22. **ASCII y píxeles** (*ASCII and pixels*). Construye una silueta o escena con caracteres o píxeles visibles y conserva la tipografía funcional como una capa separada.

## Compara, corrige y verifica

1. Mantén el contenido y la composición al comparar la versión base con las dos variantes. Por ejemplo, para una portada de rutas, compara un paisaje de un solo matiz, que separa planos por luminosidad, con curvas de nivel, que sugieren el relieve sin ocupar toda la escena.
2. Revisa cada variante al tamaño final y en los recortes previstos. Comprueba el contraste del texto y los controles sobre las zonas más claras, oscuras o densas que puedan quedar debajo. Confirma que el elemento prioritario se identifica primero y que el patrón se distingue a escala real.
3. Si el fondo compite con el contenido, reduce su intensidad o densidad, cambia el encuadre o añade una superficie de lectura. Vuelve a revisar los tamaños afectados tras el ajuste.
4. Entrega el tratamiento elegido, la zona donde aplicarlo, el ajuste realizado y el resultado de la comparación. Si solo dispones de una descripción, presenta la propuesta como especificación e indica qué comprobaciones requieren un render.
